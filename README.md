# Bioshock_ecomm_new

This Ecommerce website is designed to mimic the ideas of purchasing the various Vigor's and Plasmids that you can get throughout the Bioshock franchise. 

Description <br>

This is a parody website about purchasing Plasmids and Vigor's from the Bioshock games with either Salt or Adam. This website puts you in the seat of wanting to image purchasing and shopping as a sort of ideal Ecommerce site that allows you to live out the fantasy of having electrical powers or being able to summon a bunch of Crows on a person. 

This Project also has the interactable actions of seeing what items are in your cart where you are able to remove and add them at will. Which comes in handy when you dont want to go over your Adam or Salt budgets.

Time to get Started with the dependencies <br>

This project requires a modern version of Node.js. It was built using the following versions:

React: ^19.2.0
React-DOM: ^19.2.0
Vite: ^6.0.0
Installing
Clone the repository: https://github.com/TylerConwell/Bioshock_ecomm.git

Navigate to the folder: cd Bioshock_ecomm\Bioshock_ecomm_new\bioshock_template

Install dependencies:
npm install
Executing Program
To run the program in development mode:

npm run dev
